# Arkham Cards

App is currently in early <b>Beta</b>. Final goal to have most of features from previous [ArkhamCards](https://github.com/zzorba/ArkhamCards) app and also implement very useful ones from [arkham.build](https://github.com/arkham-build/arkham.build).

## Translations
Translation data for all of the cards comes from ArkhamDB.com, and is community managed. You can submit edits for cards in the [arkhamdb-json-data](https://github.com/kamalisk/arkhamdb-json-data/) project with a pull request.

App itself is currently translated into English, Russian, German, French, Spanish, Italian, Polish, Portugues, Korean, Chinese and Chinese (Simplified).
To translate app copy strings elements from `strings.xml` in [app/src/main/res](https://github.com/Evgeny727/ArkhamCards2.0/tree/master/app/src/main/res) folder to `strings.xml` in `./src/main/res/values-`your-locale-code. If folder doesn't exist, please open an issue for adding your locale. Translations files should not include strings with `translatable="false"`. <b>Note:</b> later will be available script to pull all not translated strings to your locale.
